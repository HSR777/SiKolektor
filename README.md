# SiKolektor — Aplikasi Absensi & Laporan Kunjungan Kolektor

SiKolektor adalah aplikasi mobile berbasis Android native yang dirancang 
untuk membantu agen kolektor lapangan dalam mencatat kehadiran dan 
melaporkan kunjungan nasabah secara digital. Aplikasi ini menyediakan 
fitur absensi real-time, pencatatan kunjungan harian, dan riwayat 
aktivitas lapangan dalam antarmuka yang sederhana dan mudah digunakan.

## Teknologi yang Digunakan

- **Native Android**: Platform pengembangan aplikasi mobile.
- **Java**: Bahasa pemrograman utama.
- **Android Studio**: IDE untuk pengembangan dan pengujian aplikasi.
- **MySQL**: Database untuk menyimpan data absensi dan kunjungan.

## Fitur Utama

- Login — autentikasi pengguna dengan validasi akun
- Dashboard — ringkasan aktivitas harian agen
- Absen Masuk & Pulang — pencatatan waktu kehadiran berbasis waktu nyata
- Daftar Kunjungan — pencatatan kunjungan nasabah per hari
- Riwayat Kunjungan — rekap historis kunjungan yang telah dilakukan
